# Minha Lista de Tarefas

Aplicação web de lista de tarefas (to-do list) que permite adicionar, editar, concluir e remover tarefas. As tarefas ficam salvas no navegador através do `localStorage`, então continuam lá mesmo depois de fechar a página.

Projeto desenvolvido durante o Curso Técnico.

## 🔗 Link: **https://giovana-v.github.io/Minha-Lista-de-Tarefas/**

## Funcionalidades

- ➕ Adicionar novas tarefas
- ✏️ Editar uma tarefa existente (com Enter para salvar e Esc para cancelar)
- ✅ Marcar tarefa como concluída (clicando no texto)
- 🗑️ Remover tarefas
- 💾 Salvamento automático no navegador (`localStorage`)

## Tecnologias

- HTML5
- CSS3
- JavaScript
